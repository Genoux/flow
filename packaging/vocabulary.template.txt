# HOW IT WORKS
# The terms are given to the cleanup model as context - they are not searched
# and replaced. That matters: "flow" and "Flow" are both real words, and only
# the sentence around them says which one you meant, so the model decides.
#
# It reliably fixes a term that SOUNDS CLOSE to what you said:
#   "hyper land"  -> Hyprland
#   "pipe wire"   -> PipeWire
#   "post grass"  -> Postgres
#
# It cannot fix one that sounds nothing like the target. If a name comes out
# as an unrelated everyday word, adding it here will not rescue it - the sound
# the recogniser heard has no path back to the spelling you want.
#
